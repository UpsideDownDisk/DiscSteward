# Changelog

## 0.3.0 — 2026-09-24

First prepared public source release.

- Windows interface for Blu-ray and DVD programme mapping and MakeMKV automation.
- Exact disc lookup against TheDiscDb, including supported DVD disc identifiers.
- Local SRT/ZIP matching using the middle two quarters of embedded subtitle timing.
- Preferred language, series filtering, and reuse of previously matched subtitles.
- Plex rename previews, rename within the current folder, and recorded move history.
- Manual review for uncertain matches and clearly labelled numbering suggestions.
- Disc watching, recovery from interrupted rips, and mapping from saved disc evidence.
- Readable text/JSON reports and consistent duration display.
- MIT licence, source-release packaging and automated Windows checks.

This release distributes source code; it is not a standalone Windows executable.
